# Nimbus Sensor N-200 Specification Sheet

| Attribute | Value |
|---|---|
| Sampling interval | 60 seconds |
| Operating temperature | -20 C to 55 C |
| Calibration threshold | 3.5 percent optical reference drift |
| Battery service interval | 24 months |
| Radio protocol | LoRaWAN Class A |

The calibration threshold is a maintenance trigger, not an accuracy guarantee after the sensor has been exposed to abnormal particulate load.
