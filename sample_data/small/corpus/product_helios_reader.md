# Helios Reader H9 Handling Guide

Reader H9 uses a replaceable secure media module. Alert HRD-9C03 indicates that the module serial number does not match the enrollment record. Re-enroll the module after confirming the asset tag. Do not copy an enrollment file between readers.

The reader can scan badges in offline mode for up to twelve hours, but offline scans must be reconciled before access records are considered final.
