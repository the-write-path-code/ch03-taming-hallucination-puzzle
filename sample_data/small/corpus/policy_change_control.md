# Change Control Standard

Document ID: `CC-17`
Document type: policy

Clause CC-17 requires two independent approvals for a production change that modifies authentication, authorization, cryptographic material, or network segmentation. The request must name a rollback owner and include a verification window.

Emergency changes may proceed with one approval only when an active service outage is documented. The missing approval must be recorded within one business day. A routine firmware update is not automatically an emergency change.
