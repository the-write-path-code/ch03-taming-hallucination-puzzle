# Nimbus Sensor N-200 Service Note

Document ID: `NSN-42`
Document type: product
Product: Nimbus Sensor N-200

The N-200 particulate sensor reports calibration condition NSN-42 when its optical reference drift exceeds 3.5 percent. Field teams sometimes describe this as an optical drift alert rather than a calibration condition, but both phrases refer to the same NSN-42 state. NSN-42 is resolved by running the reference-card procedure from the field kit. Replacing the battery or changing the radio channel does not correct optical drift.

The N-200 stores its last successful calibration date in the local maintenance record. Support agents should request that record before opening a replacement case.
