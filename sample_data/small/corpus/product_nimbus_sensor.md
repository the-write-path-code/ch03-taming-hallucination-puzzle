# Nimbus Sensor N-200 Service Note

The N-200 particulate sensor reports calibration condition NSN-42 when its optical reference drift exceeds 3.5 percent. NSN-42 is resolved by running the reference-card procedure from the field kit. Replacing the battery or changing the radio channel does not correct optical drift.

The N-200 stores its last successful calibration date in the local maintenance record. Support agents should request that record before opening a replacement case.
