# Support Triage Playbook

Document ID: `OPS-TRIAGE`
Document type: operations

For a reported application slowdown, gather the tenant identifier, the affected time window, request IDs, and whether the problem appears in every region. Support may describe this as collecting the case fingerprint rather than gathering triage details, but the two phrases refer to the same intake step.

The goal is to assemble enough context to distinguish a broad platform condition from one tenant's configuration issue. Do not ask the customer to repeat a workflow until the existing timestamps and request IDs have been preserved.
